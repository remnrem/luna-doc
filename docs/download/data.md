# Data

Models, example data, and other Luna resources are distributed through the
[`luna-resources` repository](https://github.com/remnrem/luna-resources/).
Get the [latest release](https://github.com/remnrem/luna-resources/releases/latest).
Use the release assets below for the data and model packages; the GitHub
source-code archives do not contain them.

| Resource | Latest download |
| --- | --- |
| Combined resource bundle | [luna-resources-bundle.zip](https://github.com/remnrem/luna-resources/releases/latest/download/luna-resources-bundle.zip) |
| Tutorial data | [luna-resources-tutorial.zip](https://github.com/remnrem/luna-resources/releases/latest/download/luna-resources-tutorial.zip) |
| POPS models | [luna-resources-pops.zip](https://github.com/remnrem/luna-resources/releases/latest/download/luna-resources-pops.zip) |
| ONNX models | [luna-resources-onnx.zip](https://github.com/remnrem/luna-resources/releases/latest/download/luna-resources-onnx.zip) |
| Prediction models | [luna-resources-predict.zip](https://github.com/remnrem/luna-resources/releases/latest/download/luna-resources-predict.zip) |
| HDPC resources | [luna-resources-hdpc.zip](https://github.com/remnrem/luna-resources/releases/latest/download/luna-resources-hdpc.zip) |
